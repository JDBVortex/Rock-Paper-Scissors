# About the Project

This is a JavaScript-based Rock Paper Scissors game created as a web development project to practice building interactive webpages.

The project allows the player to select Rock, Paper, or Scissors and compete against a randomly generated computer move. The game keeps track of wins, losses, and ties and uses browser `localStorage` to save the player's score between sessions.

# Project Overview

This project is an interactive Rock Paper Scissors game built using **HTML5, CSS3, and JavaScript**.

The player interacts with the game by selecting one of three moves. JavaScript determines the computer's move, compares both selections, calculates the result, and updates the score displayed on the webpage.

The project also uses `localStorage` to save the player's score, allowing the score to remain after refreshing or reopening the webpage.
